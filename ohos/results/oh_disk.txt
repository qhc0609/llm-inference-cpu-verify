# OpenHarmony 内核直启 · 补测：真实块设备 / cgroup
# 环境：Linux 6.6.62（x86_64_virt），QEMU/KVM，4 vCPU/4GB，CPU 直通
# 磁盘：2GB 镜像，ext4，挂 virtio-blk，cache=none
# 文件：/root/audit/big.bin 256MB，宿主机 loop 挂载写入，guest 只读
# init_disk.c：先 echo 3 > drop_caches 再 read()，冷读三次；随后不丢缓存连读三次；再做 mmap 逐页冷/热
# init_cgroup.c：把 init 关进 memory.max=768MB 的 cgroup2 组，子进程继承，再跑 thread_cost
MOUNT|dev=/dev/vda|rc=0
FILE|/root/audit/big.bin|256MB
RES|disk_cold|round=0|ms=2245.8|gbps=0.12|got_mb=256
RES|disk_cold|round=1|ms=235.4|gbps=1.14|got_mb=256
RES|disk_cold|round=2|ms=368.2|gbps=0.73|got_mb=256
RES|disk_warm|round=0|ms=49.8|gbps=5.39
RES|disk_warm|round=1|ms=42.5|gbps=6.32
RES|disk_warm|round=2|ms=42.5|gbps=6.32
RES|mmap_cold|ms=567.3|gbps=0.44|sum=2141
RES|mmap_warm|ms=0.7|gbps=359.99|sum=2141
CGROUP|mount_rc=0
RES|fork_us=187.1|us|n=200
RES|thread_create_us=113.6|us|n=2000
RES|fork_vs_thread_small_rss=1.65|x
RES|fork_us_big_rss=146.3|us|n=50
RES|fork_vs_thread_big_rss=1.3|x
